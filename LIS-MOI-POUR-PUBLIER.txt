COMMENT PUBLIER — LE PLUS SIMPLE (1 double-clic)
------------------------------------------------
Les fichiers sont DÉJÀ posés au bon endroit sur ton PC : Downloads\tigerflow-a-publier\

1. Ouvre le dossier  Downloads\tigerflow-a-publier
2. Double-clique sur  publier.cmd
3. Une fenêtre noire s'ouvre, elle affiche « Publication TigerFlow » puis se ferme.
   C'est en ligne 1 à 2 minutes après :
   https://tigerseo13-del.github.io/sastigerflow/facture-detail.html
   https://tigerseo13-del.github.io/sastigerflow/recette/


SI TU PRÉFÈRES PASSER PAR LE SITE GITHUB
----------------------------------------
1. Dézippe ce fichier.
2. Va sur https://github.com/tigerseo13-del/sastigerflow
   → bouton « Add file » (en haut à droite) → « Upload files ».
3. Glisse dans la page : facture-detail.html  ET  le dossier recette (le dossier entier,
   GitHub garde l'arborescence).
4. En bas de la page : « Commit changes ».
   Mêmes adresses en ligne 1 à 2 minutes après.
